# Dogfood: one-pass audit graph

Eight Pi runs used `opencode-go/mimo-v2.6-flash` through a disposable `pi-profile` with the local extension; later runs also loaded the package's bundled skills. The targets were fresh copies of `Testing/pi-audit-loop/dogfood/sqlite-utils` and `Testing/Agentic-Workbench` under `/private/tmp`; the source repositories stayed clean. Three exploratory runs were interrupted after the agent broadened its search or used the wrong Python environment. Five runs reached an audit outcome.

| Scenario | Observed route and outcome | Independent check |
|---|---|---|
| Workbench suppression fingerprints | Initial review clean, `complete`, no changed files | Focused suite: 5 passed; checkout clean |
| sqlite-utils `rows --limit 0` fix | `fix`, regression test failed before the code edit, final review `complete`, two changed files | Full suite: 1,486 passed, 19 skipped; diff confined to the CLI condition and one test case |
| sqlite-utils `rows --limit 0` review only | `fix` finding left open with `changed=false`; `open_findings`, no changed files | Checkout clean; source code and a two-row CLI reproduction support the finding |
| sqlite-utils WAL method simplification | `simplify`, one private helper added, final review `complete`, one changed file | Focused WAL suite: 6 passed; full suite: 1,485 passed, 19 skipped; diff preserved the two public methods, transaction error text, and no-op branch |

A completed review-only run made an unnecessary `audit_verify` call after `audit_change(changed=false)`. The extension rejected it and kept `open_findings`. The package now says explicitly that this no-op ends the audit and directs Pi to `audit_loop_status`; a fresh run followed that path without a rejected verification call.

The interrupted runs exposed a practical setup constraint: a broad task prompt led to an unrelated filesystem search, the system Python lacked project dependencies, and an absolute virtual-environment path led Pi to inspect the source checkout. Copying the environment into the disposable checkout and using `.venv/bin/python` kept the simplification run local. These were agent and environment behaviors; the extension enforces phase transitions and observed test exit codes, not search scope or semantic correctness.

No testing source repository was edited, no package was published, and the sqlite-utils changes remain only in disposable copies. The Pi JSON logs are in `/private/tmp/pi-audit-dogfood-*.jsonl` for this local session. Their model-reported costs sum to `$0.01753774` across all eight runs, including the interrupted ones.
